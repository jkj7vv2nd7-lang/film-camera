# フィルムカメラPWA 設計報告書

作成：2026-11-16（第1期着手時）

## 1. コンセプト
iPhone/iPadのブラウザで動き、ホーム画面に追加して使えるPWA形式のカメラアプリ。プレビューを見て撮るのではなく、光学ファインダー風の枠線・二重像・LED露出計だけを頼りに撮る、完全手動の「単体シャッター」体験。装填したフィルム銘柄ごとの色味と粒状感を楽しめる。

## 2. ファイル構成（承認済み）
- `index.html`（本体全部入り。フィルムプロファイルも内包）
- `manifest.json`
- `sw.js`
- ホーム画面用アイコン（絵柄入り）
- 公開はGitHub Pages。リポジトリ作成は清水さんが行う（完成時にリポジトリ名の案と手順を報告する）

## 3. 調整点（承認済み・実装への反映）
1. **ImageCaptureは使わない**：getUserMediaの映像からcanvasで切り取る方式で撮影する（iOS Safari対応のため）。
2. **二重像のフォーカスは演出**：本当のピントはカメラ側の自動焦点が裏で合わせる。画面上の説明で誤解のない表現にする（ファインダー下に明記）。
3. **横画面は強制できない**：縦持ちでも崩れない作りにし、横向きの案内を出す。

## 4. 実装する機能（仕様の要点）
- M6ブラッククロームの質感（マットな黒金属＋貼り革テクスチャ、白と赤の刻印）
- ファインダー2方式の切り替え：M6式ブライトフレーム（35/50/90mm枠＋中央の二重像枠）／バルナック式二重窓（左：距離計窓、右：構図窓）
- LED露出計：裏で動くカメラ映像の平均輝度を測光し、シャッター速度・ISO・仮想F値から露出判定して ▶ ● ◀ を点灯
- シャッター速度ダイヤル（B,1,2,4,8,15,30,60,125,250,500,1000。ドラッグ回転／タップ、クリック音つき）
- 仮想絞り（f/1.4〜16）とフォーカススライダー（0.7m〜∞、二重像のスライド連動）
- 巻き上げレバーをチャージしないとシャッターが切れない仕組み。シャッター時は布幕音＋ファインダーの一瞬のブラックアウト
- 底蓋の開閉ロックキー（OPEN/CLOSE）→フィルムパトローネ選択ドロワー→装填でISO自動セット＋背面メモホルダーに銘柄表示→底蓋を閉めて空シャッター2回でカウンター0→1
- フィルムシミュレーション：無加工（Digital Clean）／Portra 400／Cinestill 800T（ハレーション演出）／Natura 1600／Superia Venus 800・業務用100／Kodachrome 64／Tri-X 400／Neopan 400 Presto。canvasのピクセル処理でトーン・彩度・色被り・粒子を再現
- Web Audio APIで音を合成（ダイヤルのクリック、布幕シャッター、巻き上げギア、底蓋ロック）。外部音声ファイルなし。クリック音はiPhoneの小型スピーカーで聞こえる音域（1.3kHz帯を目安）
- IndexedDBに写真・装填状態・残り枚数を保存
- 現像：24枚／36枚撮り終えるか巻き戻しで取り出すと、コンタクトシート（パーフォレーションと銘柄印字つき）で一覧でき、個別に保存できる

## 7. 第1期の実装メモ
- 測光：映像を小さいcanvas（32×18）に落として平均輝度を算出し、平滑化して使う。輝度→EVの換算はシミュレーション用の較正値（実機の見え方で清水さんと調整する前提）。
- ISO：第2期のフィルム装填で自動セットされるまでの間、第1期では確認用にISO切替（100/200/400/800/1600/3200）を置く。
- LEDの意味：◀＝露出不足（暗い）／●＝適正／▶＝露出過多（明るい）。ファインダー内に小さく意味を併記する。
- 二重像：中央のパッチに映像のゴーストを重ね、フォーカススライダーでずらす。合焦位置（ゴーストが重なる位置）は被写体距離2m相当に置いた演出。実際のピントはカメラの自動焦点まかせで、その旨を画面に明記する。
- 音：Web Audio合成のみ。クリックは1.3kHz帯の短い音（iPhoneの小型スピーカーで聞こえることが確かめられた音域）。
- カメラが使えない環境では、測光と撮影ができない旨と、許可の出し方を表示する（UIの確認だけはできる）。
